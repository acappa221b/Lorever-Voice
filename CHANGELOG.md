# Changelog

## 1.0.0

- First version of Lorever Voice Studio.
- All Lorever lore texts of the level 1 to 20 lands, cities and dungeons, in English, sorted by zone.
- Record, play and delete each text. A check mark shows what is done.
- Silence at the start and the end of each take is cut automatically.
- Export (.zip) makes a voice pack folder ready for the World of Warcraft AddOns folder.
